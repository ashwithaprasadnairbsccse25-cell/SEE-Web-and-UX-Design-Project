About ClarityWeather

ClarityWeather is a student project built to demonstrate web design, JavaScript API usage, and responsive UX. It showcases a simple, modern design and live weather data using OpenWeatherMap.

Features

  • Current weather for any city
  • 5-day forecast powered by OpenWeatherMap
  • Responsive blue ocean UI
  • Dark / Light theme toggle
  • Animated waves, clouds, and floating bubbles
